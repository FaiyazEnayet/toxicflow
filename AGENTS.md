# Instructions for coding agents

Before changing this repository's dashboard, README, demo animation, generated figures, or dashboard generator, read [AGENT-DASHBOARD-GUIDE.md](AGENT-DASHBOARD-GUIDE.md). Apply its evidence, design, accessibility, and README requirements.

## This repository

- Primary language: Rust and Python.
- Dashboard generator: `scripts/dashboard.py`.
- GitHub Pages artifact: `docs/dashboard.html`.
- Keep this repository's design identity, real data sources, model assumptions, interactions, provenance, and limitations intact. Do not make up metrics or claim tests passed without running them.
- When chart data or meaning changes, update the rendered dashboard and the README's supported claims, result figure, and data animation as needed in the same change.
- Open the generated HTML locally, check its main interaction and desktop/mobile layout, compare metrics to source, and report exact checks and limitations.
